HOW THE SPEECH SYSTEM WORKS
=============================================================================

OpenClaw Mouth is the OUTPUT companion to OpenClaw Ears (voice INPUT).

Flow:
  1. You (the agent) write text to ~/.molt-speak/runtime/speech_output.txt
  2. Speech system detects the new text
  3. Text is synthesized to speech using Edge-TTS
  4. Speech plays through the computer's speakers
  5. Your user hears your response!

It's that simple. Just write text to a file, and it will be spoken.

SPEAKING SIGNAL FOR COORDINATION:
  - The system automatically creates a signal file at:
    ~/.molt-speak/runtime/mouth_status.txt
  - This file indicates when you're speaking (status: SPEAKING, IDLE, etc.)
  - OpenClaw Ears monitors this to pause listening while you speak
  - You don't need to do anything - it's automatic!
  - The terminal shows a green "AGENT SPEAKING" banner when active
  - See SPEAKING_SIGNAL.md for full integration details

=============================================================================
STEP 1: START THE SPEECH SYSTEM
=============================================================================

Open a terminal window and run:

    cd ~/.molt-speak/open_mouth
    ./start_speech_system.sh

You should see a terminal interface showing:
  - Status: IDLE / SPEAKING / QUEUED
  - Current text being spoken
  - Progress bar
  - Voice being used
  - Queue status

Leave this terminal window open - the speech system runs here.

=============================================================================
STEP 2: WRITE TEXT TO SPEAK
=============================================================================

To make the system speak, write to the file:

    ~/.molt-speak/runtime/speech_output.txt

Example in Bash:
    echo "Hello! How can I help you today?" >> ~/.molt-speak/runtime/speech_output.txt

Example in Python:
    with open(os.path.expanduser("~/.molt-speak/runtime/speech_output.txt"), "a") as f:
        f.write("Hello! How can I help you today?\n")

The speech system monitors this file and automatically speaks any new lines.

=============================================================================
STEP 3: MULTIPLE MESSAGES
=============================================================================

You can queue multiple messages by writing multiple lines:

    echo "First message" >> ~/.molt-speak/runtime/speech_output.txt
    echo "Second message" >> ~/.molt-speak/runtime/speech_output.txt
    echo "Third message" >> ~/.molt-speak/runtime/speech_output.txt

The system will speak them in order.

=============================================================================
IMPORTANT NOTES
=============================================================================

1. FILE APPEND ONLY
   - Always use >> (append) not > (overwrite)
   - Each line becomes a separate utterance
   - Empty lines are ignored

2. TEXT FORMATTING
   - Keep text natural and conversational
   - Avoid special characters that don't read well
   - Emojis will be skipped
   - Markdown formatting will be read literally

3. QUEUE MANAGEMENT
   - System queues up to 10 messages
   - If queue is full, wait or increase MAX_QUEUE_SIZE
   - Check terminal display for queue status

4. PERFORMANCE
   - First utterance has ~1-2 second latency (synthesis)
   - Subsequent utterances are queued and processed
   - System runs continuously - no restart needed

PATTERN 1: Simple Bash Script

#!/bin/bash
SPEECH_FILE="$HOME/.molt-speak/runtime/speech_output.txt"

speak() {
    echo "$1" >> "$SPEECH_FILE"
}

PATTERN 2: Python Function
---------------------------
import os
from pathlib import Path

def speak(text: str) -> None:
    """Send text to OpenClaw Mouth for TTS."""
    speech_file = Path.home() / ".molt-speak/runtime" / "speech_output.txt"
    with open(speech_file, "a") as f:
        f.write(f"{text}\n")

# Usage
speak("Hello from Python!")


PATTERN 3: With Error Handling
--------------------------------
import os
from pathlib import Path

def speak_safe(text: str) -> bool:
    """Send text to speech system with error handling."""
    try:
        speech_file = Path.home() / ".molt-speak/runtime" / "speech_output.txt"
        speech_file.parent.mkdir(exist_ok=True)

        with open(speech_file, "a") as f:
            f.write(f"{text}\n")

        return True

    except Exception as e:
        print(f"Failed to speak: {e}")
        return False

=============================================================================
TROUBLESHOOTING
=============================================================================

Problem: Nothing is being spoken
---------------------------------
1. Check if speech system is running (look for terminal window)
2. Verify file path: ~/.molt-speak/runtime/speech_output.txt
3. Check file permissions
4. Look at speech system terminal for errors

Problem: Speech is garbled or wrong voice
------------------------------------------
1. Check voice setting in speech system
2. Restart with different voice:
   ./start_speech_system.sh --voice en-US-AriaNeural

Problem: Messages are delayed
------------------------------
1. Check queue size in terminal display
2. Queue might be full or system is catching up
3. Normal latency is <1 second per message

Problem: System crashed
-----------------------
1. Check speech system terminal for error messages
2. Restart: ./start_speech_system.sh
3. Report error to user (don't try to fix the code)
