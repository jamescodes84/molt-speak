# Claude Integration with OpenClaw

## Overview

This integration allows Claude to speak through OpenClaw Mouth in real-time, streaming responses sentence-by-sentence for instant playback.

## How It Works

```
User Input → Claude API (streaming) → ~/.openclaw/speech_output.txt → OpenClaw Mouth → Audio Output
```

Each sentence is:
1. Generated by Claude in real-time
2. Written to the speech file immediately
3. Detected within 50ms by the file monitor
4. Synthesized and spoken within ~100ms (with --local)

**Total latency: ~150ms from sentence completion to speech start**

## Files

- `claude_speak.py` - Main integration script
- Uses Claude's streaming API
- Buffers by sentence for natural speech flow

```python
# Example bridge script
from pathlib import Path
import anthropic
import re

def handle_user_speech(user_text: str):
    """Called when OpenClaw Ears detects speech"""
    client = anthropic.Anthropic(api_key="your-key")
    speech_file = Path.home() / ".openclaw" / "speech_output.txt"

    buffer = ""
    sentence_pattern = re.compile(r'([.!?])\s+')

    with client.messages.stream(
        model="claude-sonnet-4-5-20250929",
        max_tokens=2048,
        messages=[{"role": "user", "content": user_text}]
    ) as stream:
        for text in stream.text_stream:
            buffer += text

            match = sentence_pattern.search(buffer)
            if match:
                sentence = buffer[:match.end()].strip()
                with open(speech_file, "a") as f:
                    f.write(sentence + "\n")
                    f.flush()
                buffer = buffer[match.end():]

        if buffer.strip():
            with open(speech_file, "a") as f:
                f.write(buffer.strip() + "\n")
                f.flush()
```

## Performance

- **Detection:** 50ms (aggressive polling)
- **Synthesis (local):** <100ms (macOS `say`)
- **Synthesis (cloud):** 1-2 seconds (Edge-TTS)
- **Total (local):** ~150ms per sentence
- **Total (cloud):** ~2 seconds per sentence

**Recommendation:** Always use `--local` for real-time conversation.

## Troubleshooting

**Issue:** Nothing speaks
**Fix:** Make sure OpenClaw Mouth is running with `--local`

**Issue:** Whole response speaks at once
**Fix:** You're using the old code. Make sure you're using `claude_speak.py` which streams sentence-by-sentence

**Issue:** API errors
**Fix:** Check your API key with:
```bash
echo $ANTHROPIC_API_KEY
```

**Issue:** Slow speech
**Fix:** Use `--local` flag for instant synthesis

## Example: Full Conversation System

```python
#!/usr/bin/env python3
"""
Full OpenClaw conversation system with Claude
"""
import os
import re
from pathlib import Path
import anthropic
import time

# Paths
SPEECH_OUTPUT = Path.home() / ".openclaw" / "speech_output.txt"
VOICE_INPUT = Path.home() / ".openclaw" / "transcription.txt"

# Initialize Claude
client = anthropic.Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

# Conversation history
conversation = []

def speak_response(user_input: str):
    """Stream Claude response to speech"""
    conversation.append({"role": "user", "content": user_input})

    buffer = ""
    sentence_pattern = re.compile(r'([.!?])\s+')
    full_response = ""

    with client.messages.stream(
        model="claude-sonnet-4-5-20250929",
        max_tokens=2048,
        messages=conversation
    ) as stream:
        for text in stream.text_stream:
            full_response += text
            buffer += text

            match = sentence_pattern.search(buffer)
            if match:
                sentence = buffer[:match.end()].strip()
                with open(SPEECH_OUTPUT, "a") as f:
                    f.write(sentence + "\n")
                    f.flush()
                buffer = buffer[match.end():]

        if buffer.strip():
            with open(SPEECH_OUTPUT, "a") as f:
                f.write(buffer.strip() + "\n")
                f.flush()

    # Add to conversation history
    conversation.append({"role": "assistant", "content": full_response})

def monitor_voice_input():
    """Monitor for new voice input from OpenClaw Ears"""
    last_position = 0

    while True:
        try:
            if VOICE_INPUT.exists():
                with open(VOICE_INPUT, "r") as f:
                    f.seek(last_position)
                    new_text = f.read()
                    last_position = f.tell()

                    if new_text.strip():
                        print(f"[USER] {new_text.strip()}")
                        speak_response(new_text.strip())

            time.sleep(0.1)

        except KeyboardInterrupt:
            break

if __name__ == "__main__":
    print("OpenClaw + Claude conversation system running...")
    monitor_voice_input()
```
