=============================================================================
SYSTEM COMPONENTS
=============================================================================

Three systems work together:

1. OPENCLAW EARS (Voice Input)
   - Listens to user's voice
   - Transcribes speech to text
   - Types text into your TUI
   - Pauses when you're speaking (echo prevention)

2. OPENCLAW MOUTH (Voice Output)
   - Monitors ~/.openclaw/speech_output.txt
   - Synthesizes text to speech
   - Plays audio through speakers
   - Signals when speaking

3. INTEGRATION COORDINATOR (Echo Prevention)
   - Monitors when Mouth is speaking
   - Signals Ears to pause microphone
   - Prevents feedback loop
   - Resumes Ears when done

All three run in separate terminal windows.

HOW TO SEND VOICE OUTPUT (YOU → MOUTH)
=============================================================================

To speak to your user, write text to the file:

    ~/.openclaw/speech_output.txt

Example in Bash:
    echo "It's sunny, 72 degrees" >> ~/.openclaw/speech_output.txt

Example in Python:
    import os
    speech_file = os.path.expanduser("~/.openclaw/speech_output.txt")
    with open(speech_file, "a") as f:
        f.write("It's sunny, 72 degrees\n")

Example in your agent code:
    def speak(self, text):
        """Speak text to the user via OpenClaw Mouth."""
        speech_file = Path.home() / ".openclaw" / "speech_output.txt"
        with open(speech_file, "a") as f:
            f.write(f"{text}\n")

    # Usage:
    self.speak("Hello! How can I help you today?")

IMPORTANT: Use APPEND mode (>>  or "a") not write mode (> or "w")!

=============================================================================
ECHO PREVENTION (HOW IT WORKS)
=============================================================================

The Integration Coordinator prevents your voice from triggering commands:

1. You write text to speech_output.txt
2. Mouth starts speaking
3. Mouth updates status: ~/.openclaw/mouth_status.txt (SPEAKING)
4. Coordinator detects SPEAKING status
5. Coordinator creates: ~/.openclaw/ears_pause.signal
6. Ears checks signal → PAUSES MICROPHONE (clears buffer)
7. Your voice plays but doesn't trigger transcription
8. Mouth finishes → Status changes to IDLE
9. Coordinator removes pause signal (after 200ms)
10. Ears resumes listening

This happens automatically - you don't need to do anything!

=============================================================================
BEST PRACTICES FOR AGENTS
=============================================================================

1. ACKNOWLEDGE VOICE COMMANDS
   When you receive voice input, acknowledge it:

   User says: "Check my calendar"
   You speak: "Checking your calendar now..."
   Then process the command

2. KEEP RESPONSES NATURAL
   Voice conversations are different from text:
   ✅ "It's sunny today, 72 degrees"
   ❌ "Weather: Sunny, Temp: 72°F, Humidity: 60%"

3. HANDLE FRAGMENTED INPUT
   Voice transcription isn't perfect:
   - "weather in Paris" might arrive as "whether in Paris"
   - Use fuzzy matching and context
   - Ask for clarification if needed

4. PROVIDE AUDIO FEEDBACK
   Let user know you're working:
   - "Let me check that for you..."
   - "One moment please..."
   - "I'm searching for that information..."

5. ONE THOUGHT PER UTTERANCE
   Break long responses into multiple lines:

   echo "I found three restaurants nearby." >> ~/.openclaw/speech_output.txt
   echo "First is Chez Pierre, rated 4.5 stars." >> ~/.openclaw/speech_output.txt
   echo "It's open until 10 PM tonight." >> ~/.openclaw/speech_output.txt

6. AVOID SPECIAL CHARACTERS IN SPEECH
   - Numbers: "twenty-two" works better than "22"
   - Symbols: "at" instead of "@"
   - Keep it conversational

AUTOMATIC STARTUP DETECTION
=============================================================================

When the integration coordinator starts, it creates:
    ~/.openclaw/agent_instructions.active

This file contains these full instructions. Your agent should:

1. Check for this file on startup
2. Read and process the instructions
3. Enable voice capabilities

Example detection code:

```python
from pathlib import Path

def check_voice_loop_status():
    """Check if voice loop is active."""
    active_file = Path.home() / ".openclaw" / "agent_instructions.active"
    shutdown_file = Path.home() / ".openclaw" / "agent_shutdown.signal"

    if shutdown_file.exists():
        print("⚠️  Voice loop was shut down")
        # Read shutdown message
        print(shutdown_file.read_text())
        # Clean up
        shutdown_file.unlink()
        return False

    if active_file.exists():
        print("✅ Voice loop is ACTIVE!")
        # Read instructions
        instructions = active_file.read_text()
        print(instructions)
        return True

    print("Voice loop not active")
    return False

# Call on agent startup:
voice_loop_active = check_voice_loop_status()
```

SAMPLE AGENT INTEGRATION CODE
=============================================================================

Here's a simple helper for your agent:

```python
from pathlib import Path

class VoiceInterface:
    """Simple interface for OpenClaw voice loop."""

    def __init__(self):
        self.speech_file = Path.home() / ".openclaw" / "speech_output.txt"
        # Ensure directory exists
        self.speech_file.parent.mkdir(parents=True, exist_ok=True)

    def speak(self, text: str) -> None:
        """Speak text to the user via OpenClaw Mouth."""
        with open(self.speech_file, "a") as f:
            f.write(f"{text}\n")

    def speak_multiple(self, texts: list[str]) -> None:
        """Speak multiple utterances in sequence."""
        with open(self.speech_file, "a") as f:
            for text in texts:
                f.write(f"{text}\n")

# Usage in your agent:
voice = VoiceInterface()

# When you receive voice input (comes automatically via TUI)
user_input = input()  # "What's the weather?"

# Process and respond
response = process_command(user_input)

# Speak response
voice.speak(response)
```

SHUTDOWN DETECTION
=============================================================================

When the integration coordinator stops, it creates:
    ~/.openclaw/agent_shutdown.signal

And removes:
    ~/.openclaw/agent_instructions.active

Your agent should periodically check for this or handle it on next startup:

```python
import time
import threading

def monitor_voice_loop_status():
    """Background thread to monitor voice loop status."""
    shutdown_file = Path.home() / ".openclaw" / "agent_shutdown.signal"

    while True:
        if shutdown_file.exists():
            print("🔴 Voice loop shut down!")
            shutdown_msg = shutdown_file.read_text()
            print(shutdown_msg)

            # Disable voice capabilities
            voice_interface.disable()

            # Clean up
            shutdown_file.unlink()
            break

        time.sleep(5.0)  # Check every 5 seconds

# Start monitoring in background:
monitor_thread = threading.Thread(target=monitor_voice_loop_status, daemon=True)
monitor_thread.start()
```
